## Description

A platform designed to automate the reading and processing of invoices and payment slips using OCR for automatic data extraction, significantly reducing the need for manual data entry. I developed both the [frontend](https://github.com/MarcusGANunes/invoice-summary) and the [backend](https://github.com/MarcusGANunes/invoice-summary-backend) of the application, implementing user authentication, database integration, REST APIs, and a responsive interface for data visualization and management, following best practices in software architecture, code organization, and TypeScript development.

**Technologies used:** Next.js, React, NestJS, TypeScript, Prisma (ORM), and SQLite.
